# Code v1.1.0 reproduction scope

This release supplies the unchanged portable inference/statistics interfaces and all 46 inspectable historical training/analysis sources. The added snapshot includes the grade-value auxiliary module/objectives, alpha-search and training controllers, DeiT training, matched auxiliary controls, reference reconstructions, selection and evaluation lineage. SOURCE_LICENSE_ATTRIBUTION.json/CSV binds every public file to its raw R16 source SHA and applicable attribution.

The snapshot is not a newly portable training pipeline. It uses explicit /PATH/TO/... placeholders; original private parent assets, source/import and identity gates remain. Some controllers have module-level effects and must not be casually imported or run. Three embedded-ID auditors instead require the user-supplied exact original source CSV, with the historical test-ID-set hash and separately dated current official-CSV byte hash; missing/different input fails, and no replacement split is generated.

Full historical reproduction still needs authorised source MRI/labels, correct frozen patient/ROI split and identity mapping, distinct CNN IQ8/historical DeiT PNG representations, parent result archives, relevant initial pretrained assets and the historical training environment. The retained Linux CPU inference constraints are an earlier inference installation record, not a historical training lock. Initial pretrained-file identity, augmentation/dependency locking and full portability limits remain disclosed.

All 32 portable Python files, both pyproject.toml files (package version 1.0.0), frozen statistic kernels/plans and fusion bytes are unchanged from public v1.0.1. No legacy source was executed/imported; only AST parsing, text sanitation, hashing and packaging checks were performed. No new training, inference, statistics, bootstrap or selection occurred. No raw images, real patient/ROI rows, source split rows, models or credentials are bundled.

# Immutable historical preparation evidence

The JSON files here are unchanged copies of earlier R16-parent preparation records, including retained R3-R16 verification history. Their hashes refer to the original candidates named in each record. These records may state that their original candidate was unpublished or awaiting an author licence; those are historical facts, not current v1.1.1 code licence status.

R4: fresh isolated Linux Python 3.11 CPU dependency installation on the same host; 50 strict architecture loads and artificial forward interfaces. R5: bound-metadata strict loading. R6/R7: common5 example/path contracts with artificial inputs. R9: common5 float64 arithmetic correction, 30 runtime tests, 70 frozen numeric cases, ten artificial-image cases. R11/R12: direct/robustness statistics interfaces with explicit frozen inputs and artificial contract checks. Later rounds preserve the scope and origin of this evidence.

No tests, model forward calls, training, bootstrap, selection or performance calculations are rerun for v1.1.1 packaging. Full internal candidate membership and then-current digests are not the membership/digests of this public subset. Present distribution integrity and current program maps are in ../PUBLIC_DISTRIBUTION_MANIFEST.json, ../CODE_MODEL_COMPATIBILITY.json and ../SHA256SUMS.

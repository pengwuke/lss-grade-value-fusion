# Included historical training and analysis source snapshot

Code v1.1.0 adds all 46 retained historical source files under historical_sources/, preserving their original names/hierarchy: 42 Python files and four archived Python-text producers. Original internal R16 source hashes and public-snapshot hashes are both listed in SOURCE_LICENSE_ATTRIBUTION.json/CSV. The older historical_source_inventory.json and historical_source_manifest.json remain unchanged metadata for raw R16, not hashes of the sanitised public files.

Twenty-one public copies match their originals byte-for-byte; twenty-five have explicit placeholder paths and, for three source auditors, the external split-input gate documented below. The raw R16 sources are unchanged. This closes the inspectable training-source gap; it does not claim full historical training portability, a locked historical environment or a rerun. See HISTORICAL_TRAINING_SOURCES.md, PUBLIC_SOURCE_DIFF.patch and TRAINING_REPRODUCTION_SCOPE.md.

Three original auditor copies embedded the same 94 published dataset-internal test IDs. Those literals are not redistributed. Supply the original Phadke data/splits.csv through PAPER2_SOURCE_SPLITS_CSV. The placeholder adapter checks its patient/split columns, 94 unique test IDs, the exact original canonical test-ID-set SHA, and an additional official-CSV byte SHA measured 2026-11-09 (not retroactively claimed historically frozen). It fails clearly if missing or different; it never invents a new split. Original other source/asset hash gates remain in force.

PUBLIC_SOURCE_DIFF.patch masks removed original private roots and ID values; it is an audit diff, not a promise that all removed private inputs can be reconstructed publicly. Exact unmasked diffs remain in the private server audit directory. Sanitised file bytes may intentionally fail original raw-source SHA gates; use the declared original/public identities correctly.

The ORNet trio is the author's distinct CORAL-specific implementation of the cited method, not upstream ORNet source redistribution; no MIT licence is asserted for that upstream repository. This per-file assessment identifies no nontrivial unlicensed copied code, while recording the evidence limits rather than certifying all third-party ownership.

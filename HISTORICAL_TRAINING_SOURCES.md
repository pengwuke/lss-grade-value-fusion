# Historical training and analysis source snapshot for manuscript B15

Source component of code v1.1.1, unchanged from public v1.1.0. This snapshot supplies all 46 retained historical sources (42 .py and four .py.txt), including the grade-value auxiliary head/objectives, alpha search/training controllers, DeiT training, matched controls, reconstruction references and fusion/evaluation lineage. It complements the separate portable code release; it does not replace that runtime or claim full training portability.

Author contributions are MIT, with explicit unchanged upstream notices in THIRD_PARTY_NOTICES.md and per-file SOURCE_LICENSE_ATTRIBUTION.json/CSV. Original source SHA values bind the full unmodified internal R16 files; public SHA values bind this sanitised snapshot. PUBLIC_SOURCE_DIFF.patch lists the limited modifications while masking the omitted original private roots and split IDs. The exact full diff stays in a private server audit directory and is not part of this public review payload.

Changes are limited to explicit /PATH/TO/... placeholders and replacing three embedded copies of the public source's 94 test IDs with a strict external-input loader. Supply the original published Phadke data/splits.csv via PAPER2_SOURCE_SPLITS_CSV. The loader requires its patient/split columns, exactly 94 unique four-digit test IDs and the frozen original canonical ID-set hash. Missing or changed inputs fail clearly; no substitute split or new split is invented. No CSV rows/IDs are bundled. Other original split and asset SHA gates remain unchanged.

These are historical controllers, not a newly portable training product. Some have module-level effects; do not import or run them casually. Placeholder paths require explicit local preparation. Sanitised source bytes differ from original source hashes, so original identity gates referring to archived raw files will not automatically accept the public snapshot. Full historical reproduction also needs authorised data/labels, original split/ROI representations, parent assets, initial pretrained files and the historical environment. No dependency lock or new-machine/full-training claim is made.

No training source was executed or imported to prepare this snapshot. Only AST parsing, text transformation, hashing and archive verification were performed. No model inference, bootstrap, statistics, training, selection or new experiment ran. No MRI, ROI image/cache, real patient/ROI predictions, probability rows, fold table, model weights, credentials or private IP address is shipped. Published aggregate/source counts in comments are not new validation.

The map describes evidence of author lineage and compatible source attribution; it does not certify all third-party rights. In particular, the ORNet official repository does not expose an express licence: this snapshot contains the author's distinct CORAL-specific implementation of the cited mechanism, not that repository's implementation. No MIT grant is asserted for upstream ORNet itself. See the precise comparison and source URLs in THIRD_PARTY_NOTICES.md.
